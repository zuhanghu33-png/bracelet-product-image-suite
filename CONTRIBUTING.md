# Contributing

Contributions are welcome. Keep changes focused on source-faithful bracelet product imagery.

Before opening a pull request:

1. validate every modified skill with Codex's `quick_validate.py`;
2. keep user photographs, generated customer assets, credentials, and local absolute paths out of the repository;
3. document any new dependency;
4. preserve the rule that unseen product structure and viewpoints must not be invented.

By contributing, you agree that your contribution is licensed under the MIT License.
